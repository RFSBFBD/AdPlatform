# Integrated conformance acceptance contract, working draft

24 November 2026. Baseline b9cad35. NOT a compliance certificate, source release, operational approval or narrowed lead-only plan. The full original Master Specification remains the target. Numeric example budgets, thresholds, probabilities and provider availability in that proposed architecture are not production facts or selected owner inputs.

## Acceptance states

- LOCAL: an executable contract with independent synthetic/reference evidence can be finished without external effects.
- EXTERNAL: actual source truth, provider entitlement or relevant empirical calibration is required in addition to local implementation.
- PARTIAL: bounded existing parts exist, but the row's integrated acceptance test does not yet pass.
- FUTURE: the original text explicitly places automatic CRM/server-side work in a later stage. Interfaces and absence must be clear; it is not secretly dropped from the roadmap.

A refusal is an essential test, not successful implementation of the requested positive capability. Passing tests is evidence for named cases, not universal correctness. A row cannot be accepted by adding a metadata marker, translating a label or counting endpoints.

## Single integrated output contract

Qualified source snapshot -> precision-preserving recorded ledger -> explicit typed objective/variables/constraints -> data/model admission and router -> solver -> independent feasibility/objective/numerical check -> current/optimized/custom and sensitivity -> immutable audit -> same-snapshot diagnostics/visual explanation. Forecasting remains a separate evidence-producing engine whose outputs have explicit assumptions, horizon and validation history. It is not a replacement for measured actuals or an oracle for allocation.

Each stage must carry the same scope identity: owned entities and hierarchy, provider/source/version, outcome/count/value definition, accounting units/currency, reporting timezone/date/window, retrieval/finality/revision evidence, population/coverage and input hash. No current-source reread may silently change a frozen scenario. Derived metrics are not independent controls.
